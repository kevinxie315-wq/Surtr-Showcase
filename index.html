          He is invulnerable while he changes form. Ragnarok mode continues into Phase III, adding 70 more ticks.

          Attacks

          Damage is shown for every phase and the selected one is highlighted. All of his damage types count as magic, so the Infernal armor set cuts them by 96%.

          Install

          • Datapack (Surtr_Datapack_v2_7.zip) goes in world/datapacks. Pack format .
          • Resource pack (Surtr_Resource_Pack_v2_7.zip) goes in resourcepacks, or is the server pack on multiplayer. Pack format .
          • Install both. Everything uses the surtr namespace and touches nothing of Jormungandr or Factions.
          • The author’s README states the packs were built and linted offline and not playtested in game. Treat every number here as what the code says.
